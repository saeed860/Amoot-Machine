# آموت ماشین | نسخه استاتیک GitHub Pages

این بسته با ظاهر نمونه اولیه فروشگاه آموت ماشین که برای WordPress/WooCommerce طراحی شده بود بازطراحی شده است: هدر تیره و سفید، نوار زرد دسته‌بندی، بنر بیل مکانیکی، کارت‌های تصویری دسته‌بندی و محصولات، نوار خدمات تیره و بخش معرفی تصویری.

## انتشار در GitHub Pages
1. تمام محتویات این پوشه (از جمله پوشه `assets`) را در ریشه مخزن GitHub قرار دهید.
2. در تنظیمات مخزن، بخش Pages را روی شاخه اصلی و پوشه ریشه تنظیم کنید.
3. پس از انتشار، سایت را با `Ctrl+F5` تازه‌سازی کنید.

## تصاویر
تمام تصاویر نمونه مورد استفاده در صفحه اصلی داخل `assets/` قرار گرفته‌اند؛ برای نمایش بنر، دسته‌بندی‌ها و محصولات به سرویس تصویر خارجی وابسته نیستند. تصاویر محلی از برش‌های عکاسیِ تصویر مرجع طراحی اولیه آموت ماشین ساخته شده‌اند تا ترکیب‌بندی و حال‌وهوای همان نمونه حفظ شود. برای استفاده تجاری، تصاویر اصلی و باکیفیت هر قطعه را جایگزین کنید.

## پنل مدیریت نمایشی
- ورود نمایشی: `admin`
- رمز نمایشی: `amoot-demo-2026`
- افزودن و ویرایش محصولات و بارگذاری تصویر از دستگاه
- ورود و خروج CSV/Excel؛ ستون `image_url` برای آدرس تصویر نیز پشتیبانی می‌شود.
- درخواست‌ها و تغییرات فقط در حافظه مرورگر فعلی ذخیره می‌شوند.

## محدودیت‌ها
این نسخه فقط فرانت‌اند استاتیک است. ورود مدیریت امن، پایگاه داده مشترک، پرداخت آنلاین، ارسال ایمیل/SMS و ثبت مرکزی سفارش‌ها نیازمند API و بک‌اند مستقل هستند. اطلاعات نمونه و قیمت‌ها صرفاً نمایشی‌اند و باید پیش از بهره‌برداری واقعی جایگزین و تأیید شوند.

## پنل مشتریان (نسخه نمایشی)
- ثبت‌نام و ورود با شماره موبایل یا ایمیل و رمز عبور
- داشبورد مشتری، ویرایش اطلاعات شخصی و تغییر رمز محلی
- مدیریت چند نشانی و انتخاب نشانی پیش‌فرض
- علاقه‌مندی محصولات و نمایش درخواست‌های استعلام ثبت‌شده توسط همان حساب
- بخش سفارش‌ها برای نمایش وضعیت سفارش‌ها پس از اتصال سامانه سفارش‌گیری
- بازیابی رمز و تأیید شماره/ایمیل تا زمان اتصال سرویس پیامک/ایمیل فقط راهنمای نمایشی دارد.

**هشدار:** این پنل برای پیش‌نمایش رابط کاربری است، نه استفاده عملیاتی. اطلاعات کاربران و رمزها در `localStorage` مرورگر ذخیره می‌شوند و رمزنگاری، نشست امن، OTP، بازیابی امن، پایگاه داده مشترک و کنترل دسترسی سمت سرور وجود ندارد. پیش از دریافت اطلاعات واقعی مشتریان باید احراز هویت و ذخیره‌سازی به بک‌اند امن منتقل شوند.
