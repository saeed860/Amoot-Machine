## Data-quality notes

- Fuel manifolds, plugs, bases, supports, caps, housings and tubes are stored as system components, not as complete filters.
- 7E-7225 is a gas-line manifold; it is not treated as a diesel-fuel component.
- 399-1475, 368-5934 and 371-4587 are UHE fuel-filter/separator products; exact machine fitment remains unverified where CAT did not publish a compatible-model list in the captured page.
- Harnesses and tubes require connector, pinout, diameter, routing and serial-range validation before ordering.
- No marine application was inferred from generic engine or generator terminology.
- No prices or inventory were invented; existing values are preserved on upsert.
