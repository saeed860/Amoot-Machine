## Extraction order

1. Start with a real model + prefix from the machine plate; do not select a prefix based only on the model family.
2. Open a specific assembly/group; parent nodes may not have a parts table.
3. Capture only visible table values: part number, exact description, diagram reference, quantity, group, model, prefix and the source URL.
4. Compare the part number against the official Cat Parts Store. Keep K-Part-only rows as `CANDIDATE` in `kpart_catalog_evidence`; do not promote them to OEM-verified records.
5. Do not infer marine/land application, price, stock or interchangeability from this index.
