## Marine application policy

Only explicit CAT `MARINE ENGINE`, `MARINE AUXILIARY`, `MARINE TRANSMISSION` or `MARINE GEAR` fitment is marked marine. In this batch:
- `151-9270` — MARINE ENGINE fitment
- `2N-7003` — MARINE ENGINE fitment
- `8M-7160` — MARINE TRANSMISSION fitment

All other records are LAND or UNVERIFIED as appropriate; a generic engine/generator listing does not imply marine use.

## Verification and data integrity

- Records with CAT model lists are `NEEDS_SERIAL_CHECK`; exact serial number and arrangement still govern fitment.
- Parts without published model fitment or with incomplete specifications are marked `REFERENCE` and application `UNVERIFIED`.
- Components such as filter bases, housings, brackets, magnets, breathers and covers are classified as components rather than falsely represented as filter cartridges.
- No prices or stock quantities were invented. New rows have null prices and stock 0; existing commercial values are preserved on upsert.
- Official CAT source URLs are stored with each catalog record.
